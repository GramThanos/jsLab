CTFLib Linux Playground

Follow the steps to complete the assignment

Step 1

Linux is an operating system, just like Windows. You may not know it but both Android and iOS are based on Linux.
This big black area at the right is a Linux terminal! Just like in movies with hacker right?... haha!

Step 2

Login using the username h4cker and the password ctflib.

To login, click on the terminal and start typing the username, then press Enter. The system will then ask you for the account's password. Again, start typing the password (to hide your password, the system do not show the characters you type) and hit Enter when you are done.
Step 3

You should now see h4cker@ctflib:~$ which means that you are logged in and the system waits for your input to execute commands.

The systems shows you the name of the user your are logged in with, the system's name and the directory you are currently at in this format user@systemname:directory$. You can see that your current user is h4cker, the system's name (aka hostname) is ctflib, and the directory you are in is ~ which means that you are the this user's home folder located at /home/h4cker/.
Step 4

Now let's run some commands!
Run the command whoami (Who am I?) to get the current user's name.

To run the command, first type the command inside the terminal and the hit Enter to execute it.
Step 5

Let's get more info about this user.
Run the command id and check what is the UID of this user.

Step 6

Check what files does the user have in the current directory by running the command ls (list).

Step 7

Maybe this hacker has saved a flag somewhere in his files... can you find it?
You can see the contents of a file by running the command cat "filename.txt".
Do you see anything interesting?

You can copy text from the terminal by highlighting it and then right clicking. If you right click on the terminal without having highlighted any text, text from your clipboard will be pasted into the terminal. Alternative you may user CTRL+SHIFT+C to copy and CTRL+SHIFT+V to paste.
Step 8

Now let's logout from this user by exiting this session. To do so, run the exit command and you will end up in the login screen again.

Step 9

The root user is the administrator account of a Linux system. The root user has unlimited access to all the parts of the system.
