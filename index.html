jsLab

Virtual machines and networks in the browser, on the TinyEMU WebAssembly engine. Nothing runs on a server.

Labs

Multi-VM

Several isolated VMs on one virtual LAN with DHCP, each with its own terminal and IP address, and a peer-to-peer chat to run between them.

Single VM

One distro booted straight into a full terminal: colours, Tab completion, copy and paste.

The labs boot the x86 and RISC-V distros TinyEMU-distros publishes. The multi-VM lab also takes the URL of any config.

Library and docs

lib/vm (VMs, snapshots), lib/volumes (persistent storage) and lib/network (the virtual network) are plain ES modules. See the repository and its docs. Licence: GPL-3.0-or-later.
